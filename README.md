# 🏥 Hospital Performance Analytics

## 📌 Overview
This project is an end-to-end Data Analytics and Business Intelligence solution designed to track and analyze hospital performance. It simulates a realistic data pipeline, from generating synthetic patient and financial records to visualizing key performance metrics in an interactive dashboard.

## 🛠️ Tech Stack
* **Data Generation & Processing:** Python (Pandas, NumPy)
* **Database Management:** SQLite, SQL
* **Data Visualization & BI:** Power BI

## 📂 Project Files
* `Healthcare_Performance.ipynb`: The core Jupyter Notebook that generates synthetic hospital data (including departments, patients, billing, and costs), structures it, and exports it to CSV and SQLite formats.
* `Healthcare_Performance_Dashboard.pbix`: The interactive Power BI dashboard containing the visual reports and business insights.
* `Healthcare_Performance_Dashboard.pdf`: A static PDF export of the dashboard for quick and easy viewing.

## 📊 Key Insights & Dashboard Features
The Power BI dashboard provides a comprehensive look into the hospital's operations, focusing on:
* **Financial Overview by Department:** Tracking Total Revenue, Total Cost, and Profit Margin across critical departments such as Oncology, Orthopedics, and Cardiology.
* **Patient Metrics:** Analyzing the Average Length of Stay to optimize bed management and departmental efficiency.
* **Billing & Claims:** Visualizing the Claim Status Distribution (Approved, Pending, Denied) to assess insurance workflow.

## ⚙️ How to Run the Project
1. Clone this repository to your local machine.
2. Run the `Healthcare_Performance.ipynb` notebook. This will execute the Python script to generate the `.db` database and `.csv` files locally.
3. Open the `Healthcare_Performance_Dashboard.pbix.pbix` file in Power BI Desktop to explore the interactive visualizations.
